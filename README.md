# 类Rust编译器前端

同济大学编译原理课程大作业（1 + 2）

---

## 项目简介

本项目实现了一个**类Rust语言**的编译器前端，涵盖词法分析、语法分析、语义分析和中间代码生成四个阶段，并提供网页前端进行可视化展示。

| 模块 | 方法 | 说明 |
|------|------|------|
| 词法分析 | 手写 DFA | 逐字符扫描，精确记录行列号 |
| 语法分析 | **手写递归下降 + 手写 LR(1)** | 两种方法均完整实现，前端可切换 |
| 语义分析 | 符号表 + AST 遍历 | 13 类静态语义错误检查 |
| 中间代码 | 四元式生成 | 覆盖所有语法结构，前端可视化展示 |
| 前端 | Flask + 原生 HTML/JS | 词法 / 语法 / 四元式 / 错误 多标签展示 |

支持的语法规则覆盖 **0.1 ~ 9.3** 全部条目，包括函数调用（3.5）、引用与借用（6.x）、块表达式（7.x）、数组（8.x）、元组（9.x）等。

## 解析器说明

本项目提供两个手写解析器，均产生完全相同的 AST 和四元式：

### 递归下降（RD）

自顶向下，每个非终结符对应一个解析函数。表达式部分采用 **Pratt 优先级爬升**解决左递归问题，`_expr(min_prec)` 参数控制结合性与优先级。

### LR(1)

手工实现完整的**规范 LR(1)** 分析器：

1. 从 86 条产生式构造 LR(1) 项目集族（615 个状态）
2. 表格首次构造约 0.3 秒，之后从 `src/__pycache__/lr1_tables.pkl` 缓存加载
3. 表达式文法按优先级分层（`cmp → add → mul → unary → postfix → primary`），消除所有运算符移进-归约冲突
4. 唯一残留冲突为悬挂 else，以**移进优先**解决

两种方法在 54 个测试样例上产生完全相同的四元式，由 `test_rd.py` 自动验证。

## 语义检查

共 13 类静态语义错误，覆盖 PDF 全部要求：

| 编号 | 规则 | 检查内容 |
|------|------|---------|
| A | 2.2/8.2/9.2 | 赋值/初始化类型不匹配 |
| B | 5.2 | `for` 循环可迭代对象必须是数组或范围 |
| C | 6.1 | 对不可变变量或其元素赋值 |
| D | 5.4 | `break` / `continue` 出现在循环体外 |
| E | 2.2/3.5 | 未声明变量或未定义函数 |
| F | 2.1/2.2 | 使用未初始化变量；声明后无法推断类型 |
| G | 1.5 | `return` 类型与函数声明不一致 |
| H | 8.2/9.2 | 数组/元组字面量大小或元素类型与声明不一致 |
| I | 3.5 | void 函数用于所有右值位置（let/赋值/参数/运算） |
| J | 6.2/6.3 | `&mut` 要求源变量可变；`&mut` 不能与任何已有借用共存 |
| K | 7.4 | 同一 `loop` 内多个 `break` 返回类型不一致 |
| L | 8.3/9.3 | 常量索引越界；元组字段索引越界 |
| M | 8.3 | 数组索引类型必须为 `i32` |

## 四元式格式

```
(op, arg1, arg2, result)
```

| 操作码 | 含义 |
|--------|------|
| `:=` | 赋值：`result = arg1` |
| `+` `-` `*` `/` | 算术运算 |
| `==` `!=` `<` `>` `<=` `>=` | 比较运算（结果 0/1） |
| `neg` | 取负：`result = -arg1` |
| `&` / `&mut` | 取引用 |
| `deref` / `deref_write` | 解引用读/写 |
| `[]` / `[]:=` | 数组元素读/写 |
| `.` / `.:=` | 元组字段读/写 |
| `alloc[]` / `alloc()` | 分配数组/元组空间 |
| `label` / `goto` / `if_false` | 跳转控制 |
| `return` | 函数返回 |
| `push_param` / `call` | 函数调用参数压栈 / 调用 |
| `func_begin` / `func_end` | 函数入口/出口 |

## 示例代码

```rust
// 函数调用（规则 3.5）
fn add(a: i32, b: i32) -> i32 { a + b }

fn main() -> i32 {
    let mut x: i32 = add(3, 4);
    x
}
```

```rust
// 引用与借用（规则 6.2 / 6.3）
fn swap(mut a: &mut i32, mut b: &mut i32) {
    let mut t: i32 = *a;
    *a = *b;
    *b = t;
}
```

```rust
// loop 表达式（规则 7.4）
fn find_first(mut arr: [i32; 5], mut target: i32) -> i32 {
    let mut i: i32 = 0;
    let mut result: i32 = loop {
        if arr[i] == target { break i; }
        i = i + 1;
        if i >= 5 { break -1; }
    };
    result
}
```

## 常见问题

**Q: `ModuleNotFoundError: No module named 'flask'`**  
A: 运行 `pip install flask ply` 后重试。

**Q: 端口 5000 被占用**  
A: 在 `src/main.py` 末尾修改 `port=5000` 为其他端口（如 5001）。

**Q: LR(1) 首次加载很慢**  
A: 首次需要构建 615 个状态的分析表（约 0.3 秒），之后从缓存加载无延迟。若需强制重建，删除 `src/__pycache__/lr1_tables.pkl`。

**Q: PLY 生成了 `parser.out` / `parsetab.py`**  
A: 正常现象，是 LALR(1) 分析表缓存文件，不影响运行。
