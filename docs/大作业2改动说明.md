## 一、问题分析：PDF 对照原项目的缺口

收到 PDF 后，对照规则逐条核查，发现以下缺口：

| 类别 | 缺口 |
|------|------|
| **语法** | 规则 3.5 函数调用（`f(args)`）完全缺失，三个解析器均不支持 |
| **语义检查** | return 类型检查、使用未初始化变量、void 函数作右值、数组/元组字面量大小与类型、借用规则、loop break 类型一致性、常量索引越界、无法推断类型 均未实现 |

| **样例** | `3.5.rs` 内容与 PDF 规则 3.5（函数调用）不符，缺乏进阶样例和错误样例 |

## 二、改动详情

### 2.1 新增 AST 节点

**文件：`src/ast_nodes.py`**

新增 `CallExpr` 节点，表示函数调用表达式（规则 3.5）：

```python
class CallExpr(Node):
    def __init__(self, name, args, lineno=None):
        self.name = name    # 函数名（字符串）
        self.args = args    # 实参列表（AST 节点列表）
        self.lineno = lineno
```

---

### 2.2 三个解析器均支持函数调用

**文件：`src/parser_rd.py`（递归下降）**

在 `_primary()` 中，遇到 `IDENT` 后紧跟 `(` 时，进入函数调用解析路径：

```
IDENT → 普通标识符（Identifier）
IDENT LPAREN args RPAREN → 函数调用（CallExpr）
```

**文件：`src/parser_lr1.py`（LR(1)）**

新增非终结符 `arg_list` 及三条产生式：

```
primary   → IDENT LPAREN arg_list RPAREN   （函数调用）
arg_list  → ε
arg_list  → expr
arg_list  → expr COMMA arg_list
```

删除旧缓存，重建 LR(1) 表（状态数从 591 增至 615）。

> `parser.py`（PLY/LALR）已在 PDF 前被停用，本次未修改。

---

### 2.3 中间代码生成支持函数调用

**文件：`src/codegen.py`**

新增两条四元式操作码：

| 操作码 | arg1 | arg2 | result | 含义 |
|--------|------|------|--------|------|
| `push_param` | 实参值 | `_` | `_` | 压入一个实参 |
| `call` | 函数名 | 实参数量 | 结果临时变量 | 调用函数，返回值存入 result |

**示例：** `add(1, 2)` 生成：
```
push_param  1   _   _
push_param  2   _   _
call        add 2   _t1
```

---

### 2.4 语义分析大幅扩充

**文件：`src/semantic.py`**

#### 新增：函数表两遍扫描

第一遍扫描注册所有函数签名（名称、参数列表、返回类型），使函数可在声明顺序无关的情况下相互调用。

#### 新增的语义检查（共 10 项）

| 编号 | 规则 | 检查内容 |
|------|------|---------|
| G | 1.5 | `return` 类型与函数声明返回类型不一致 |
| F | 2.1 | `let mut b;` 作用域结束前始终未赋值，无法推断类型 |
| F | 2.2 | 使用可能未初始化的变量（`let mut b; use(b);`） |
| N | 3.5 | 函数调用实参数量/类型与形参不一致 |
| I | 3.5 | void 函数在所有右值位置（let、赋值、参数、二元运算） |
| J | 6.3 | `&mut` 要求源变量为 `mut`；`&mut` 不能与已有任何借用共存 |
| H | 8.2/9.2 | 数组/元组字面量元素数量与声明不一致；元素类型与声明不一致 |
| K | 7.4 | 同一 `loop` 内多个 `break` 返回值类型不一致 |
| M | 8.3 | 数组索引类型必须为 `i32` |
| L | 8.3/9.3 | 常量索引越界（`a[3]` 而数组长度为 3）；元组字段越界 |

#### `Symbol` 结构扩充

新增 `initialized`（是否已赋值）和 `lineno`（声明行号）字段，用于支持 F/2.1 检查。
